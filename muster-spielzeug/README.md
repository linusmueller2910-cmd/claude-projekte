# Fließmuster

Ein kleines generatives Canvas-Spielzeug: Bewege die Maus (oder den Finger auf Touch-Geräten) über die Leinwand, um organische, fließende Farbspuren entlang eines Flow-Fields zu malen.

## Ausprobieren

Öffne [`index.html`](index.html) direkt im Browser — es sind keine Build-Schritte oder Abhängigkeiten nötig.

## Bedienung

- **Bewegen** — Maus oder Finger über die Leinwand bewegen, um zu malen
- **Leeren** — Leinwand zurücksetzen (auch per Leertaste)
- **Palette** — Farbschema wechseln
- **Speichern** — aktuelles Muster als PNG herunterladen
- **Pinsel** — Partikelgröße einstellen
- **?** — Hilfe anzeigen
